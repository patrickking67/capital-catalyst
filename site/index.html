A small ledger for your own accounts.

An early Flask app. Record transactions and holdings from the command line and add them up with exact decimals, so cents never drift. Early means early: there is no sign in and no screen that shows your data yet.

Try it

Needs Python 3.11 or newer. The key below is a fake for local use; never reuse a real secret.

git clone https://github.com/patrickking67/capital-catalyst.git
cd capital-catalyst
scripts/setup.sh
export SECRET_KEY=dev-only-not-a-real-secret

flask --app app init-db
flask --app app create-user alex             # prompts for a password
flask --app app add-transaction alex Checking 1200.50
flask --app app add-transaction alex Checking -200
flask --app app add-transaction alex Savings 500
flask --app app balances alex
flask --app app add-holding alex "Index fund" 1.5
flask --app app holdings alex

Output:

Checking: 1,000.50
Savings: 500.00
Index fund: 1.5

Bad input is refused and nothing is saved. An amount such as 1.005 fails with amount must have at most 2 decimal places. Holdings are quantities only. The app never says what they are worth.

Data model

  • User: username (3 to 64 letters, digits, dot, dash or underscore) and a password stored as a Werkzeug hash, never in plain text.
  • Transaction: account name and an amount with at most 2 decimal places. Negative means money out.
  • Investment: asset name and a quantity above zero with at most 8 decimal places.

Amounts and quantities are stored as exact decimals, not floats. The app refuses to start without a SECRET_KEY, and responses carry a strict Content Security Policy.
