# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| `main` | Yes |
| 1.0.0 and earlier | No |

## Reporting a vulnerability

Please report vulnerabilities privately at
https://github.com/patrickking67/capital-catalyst/security/advisories/new.

Do not open a public issue for a security problem. If the private form is not available, open an issue that only asks for a private contact, with no details.

Include what you found, how to reproduce it and what an attacker could do with it. Do not include real account numbers or personal financial data.

## Scope

In scope: the code in this repository (`app.py`, `models.py`, templates, static files, scripts and CI config).

Out of scope: third-party dependencies (report those upstream), and any deployment run by someone else. There is no official hosted instance.

## What to expect

This is a personal project maintained in spare time. Expect an acknowledgement within 7 days and an update on a fix or decision within 30 days.
